Bridge · 智能控制 UI 原型 v1

ESP32 继电器控制 — 主页「发现」Tab 替换为「智能控制」
方案 A：客户端直连参考中继服务器 服务端零改动 包名 switch/（区分音频中继 relay/）
功能范围（严格照 relay-control/src/main.ts 移植）：
① 单设备卡片 —— 电源环（内圈 + 旋转光环 + 脉冲光晕）+ 中心 SVG 线框图标（实线弧=开 / 虚线弧=关 / 虚线圆问号=等待）+ 设备名 + 端口 + 状态徽章（已开启·绿 / 已关闭·灰 / 等待连接·灰 / 获取中·橙）+ 开关按钮（绿=关闭设备 / 红=开启设备 / 灰等待）。
② 窗格多设备模式 —— 顶部「窗格模式」开关切换，列出全部设备，在线优先 + 服务端顺序排序。
③ 连接状态胶囊 + ⚙ 设置入口 —— 已连接·绿 / 连接中·橙 / 未连接·灰。
④ 关闭二次确认 —— 关闭供电前弹窗确认（⚠️ + 红色「确认关闭」）。
⑤ 服务器设置 —— 服务器地址 / 设备 ID / 继电器端口(1-9) / API Key，保存后重连生效。
通信模型：Bridge 客户端作为主动控制方，出站 WS 连接继电器中继服务器（默认 127.0.0.1:15152），沿用 RelaySwitchClient（OkHttp + generation 防竞态 + 指数退避重连 + 心跳判死）。

状态一：单设备卡片（三种设备状态）

设备已开启（在线）
绿色电源环 + 实线弧图标 + 绿色徽章「已开启」+ 绿色「关闭设备」按钮 + 上升粒子
设备已关闭（在线）
红色电源环 + 虚线弧图标 + 灰色徽章「已关闭」+ 红色「开启设备」按钮 + 下降粒子
设备等待连接（离线）
灰色电源环 + 虚线圆问号图标 + 灰色徽章「等待连接」+ 灰色禁用按钮 + 漂浮粒子

状态二：窗格多设备模式（每行两列卡片网格）

窗格模式（卡片网格，每行两个）
「窗格模式」开 → 每行两列紧凑卡片，同单设备卡结构，在线优先排序

状态三：交互弹窗（二次确认 + 服务器设置）

关闭设备 → 二次确认
⚠️ 图标 + 红色「确认关闭」+「取消」（复用 CoreConfirmDialog 样式）
⚙ 设置 → 服务器设置弹窗
服务器地址 / 设备 ID / 继电器端口 / API Key，保存后重连生效
设计要点与待确认项：
  • 命名隔离：新包 switch/（智能控制继电器），与项目已有 relay/（音频中继，手机放音）严格区分，二者仅同名不同义。
  • 方案 A 直连：Bridge 客户端为主动控制方，出站 WS 连接参考中继服务器（默认 127.0.0.1:15152），服务端零改动；沿用 RelaySwitchClient 的 generation 防竞态 + 指数退避重连 + 心跳判死。
  • 状态徽章语义：已开启·绿 #2E9E5B / 已关闭·灰 #8A919F / 等待连接·灰 / 获取中·橙 #E8862E。按钮颜色表示「点击后要执行的动作」：红=「开启设备」（当前已关闭）、绿=「关闭设备」（当前已开启）、灰=等待禁用 —— 严格照参考项目 btn-turn-on(红) / btn-turn-off(绿)。
  • 图标（SVG 线框，非 emoji）：严格复刻参考项目 ICONS（24×24、stroke-width=2、圆角端、stroke=currentColor）：电源环图标 powerOn(实线弧) / powerOff(虚线弧 3 3) / powerWait(虚线圆 4 4 + 问号 + 圆点)；徽章图标 badgeOn(对勾) / badgeOff(圆叉) / badgeWait(感叹号)；按钮图标 btnOn(闪电) / btnOff(电源符) / btnWait。原型用内联 <use> 引用原项目原始 d 数据 1:1 还原；Compose 端用 PathParser 解析同一份 path（RelaySwitchIcons.kt）。
  • 电源环光晕：中心图标外包「内圈淡色填充 + 旋转光环 + 脉冲光晕」，开启=绿、关闭=红、等待=灰，浅色化（保留光晕与旋转，降低透明度）。
  • 粒子特效：卡片背景叠加动态粒子 —— 开启态绿色方块上升、关闭态红色圆点下降、等待态灰色圆点漂浮，Canvas + rememberInfiniteTransition 实现（浅色淡色呈现）。
  • 关闭二次确认：复用项目已有 CoreConfirmDialog 样式（⚠️ 大图标 + 标题「确认关闭」+ 说明文案 + 红色「确认关闭」+「取消」）。
  • 服务器设置：复用项目已有「服务地址」编辑弹窗样式（四字段：服务器地址 / 设备 ID / 继电器端口 1-9 / API Key），保存后 stop() + start() 重连生效。
  • 窗格模式：进入时对所有设备 subscribe + getStatus，排序规则「在线优先 → 服务端顺序 → 中文名」。布局为卡片网格（每行两列），卡片结构与单设备卡同构（图标环 + 名称 + 端口 + 状态徽章 + 开关按钮），仅尺寸更紧凑 —— 对应参考项目 pane-grid 的 grid-template-columns: repeat(2, 1fr)。
