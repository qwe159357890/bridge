基准

口径说明

电耗 = Δ循环容量(Ah) × 平均电压(V) ÷ Δ里程(km)，即行驶这段路电池实际放出的电能。
循环容量由保护板累计（只增不减），充电不影响它；换电池 / BMS 重置会使容量回退，此时该段标记无效、不进曲线，重新以新容量为基准。
里程折扣（设置页，0.1~1.0）：三轮车表显偏大时，显示里程 = 原始值 × 折扣；电耗/花费按折扣后里程重算，原始值以括号小字保留；台账数据库存原始输入，折扣只影响显示。
花费（设置页电费单价，默认 0.6 元/度）：区间总花费 = 总耗电 × 电费；平均花费折合 元/100km = 平均电耗 × 电费 ÷ 10；每行台账花费 = 该段 kWh × 电费。

设计说明（实现时照此做）

  • 页面位置：底部导航第 3 位（首页 → 实时状态 → 统计 → 参数设置），复用提供的「统计」图标（SVG → VectorDrawable，tint 控制选中绿）。
  • 数据来源零新增协议：循环容量 cycleCapacity、总压 totalVoltage 在 0x02 实时帧里已经解析好了，录入瞬间快照即可。
  • 一行记录 = 时间 + 里程(用户输入) + 循环容量(Ah) + 总压(V)，存 DataStore JSON 列表（JikongPrefs 模式）；支持删除误录。
  • 台账排序与高度：最新记录在最上、基准垫底（倒序 LazyColumn）；卡片固定高度，条数多了内部向上滑动，不无限撑高页面。
  • 电耗口径：段电耗 Wh/km = ΔAh × 两条记录平均电压 ÷ Δkm；首页三卡 = 区间里程 / 区间总耗电 kWh / 平均电耗。
  • 守卫：新里程 ≥ 上一条（否则提示）；Δ容量 ≤ 0（BMS 重置/换电池）→ 该段标「无效」不进曲线，自动重设基准。
  • 曲线：X=里程，Y=Wh/km 折线 + 平均线；数据多后可追加月度均值视图。首条记录只做基准不出点。
  • 省电：纯录入型页面，无 GPS、无轮询；仅在点击「记一笔」时读一次当前状态。
  • 同步机制（本地为准 + 远程 MySQL 留档）：每条记录带 synced 标记与唯一 id，存本地 XML(JSON 数组)。录入永远本地成功（标「待同步」）；服务端/MySQL 离线不丢数据。台账标题右侧同步按钮：有待同步记录→可用（「同步 N 条」）；全部已同步→置灰。点击批量上传，成功 Toast + 标记翻转；失败 Toast 服务端错误原因、按钮仍可重试。服务端按 id 幂等入库（MySQL 表，重复上传不重复插行）。
  • 删除联动：删「待同步」行仅删本地；删「已同步」行→本地删除+通知远端删，远端失败进待删除队列随下次同步处理。
  • 后续可选：管理后台查看台账/曲线（服务端已有 MySQL，可后置）。
