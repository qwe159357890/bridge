# Bridge

企业级 Android 多功能应用。包名 `my.bridge.com`。

> 📚 **所有文档请查阅 [docs/INDEX.md](docs/INDEX.md)** —— 项目文档的唯一导航入口。
> 📁 **目录组织规则见 [docs/architecture/directory-convention.md](docs/architecture/directory-convention.md)**。

## 一句话了解

代码进 `app`/`core`/`feature`，文档进 `docs`，素材进 `assets`，数据进 `data`，参考进 `references`，工具进 `tools`。

## 技术栈

Kotlin 2.0.21 · Jetpack Compose · Hilt · AGP 8.13.1 · Gradle 8.10.2 · JDK 17 · minSdk 24 / targetSdk 36

## 快速开始

用 Android Studio 打开本目录，Sync Gradle 后运行 `app` 模块。

## 目录速览

| 目录 | 用途 |
|---|---|
| `app/` `core/` `feature/` | 应用代码（模块架构） |
| `docs/` | 项目文档 |
| `assets/` | 静态资源源文件 |
| `data/` | 数据类文件 |
| `references/` | 参考源码（只读） |
| `tools/` | 工具脚本 |
