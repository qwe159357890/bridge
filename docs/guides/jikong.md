# 极空（JK BMS）保护板使用文档

> Bridge 客户端内置「极空（JK）锂电池保护板」蓝牙监控能力：扫描连接、实时数据、语音播报、里程统计、靠近自动连接。
> 开发过程与修复记录见 `docs/dev/jikong-change-ledger.md`；调研与设计见 `docs/research/jikong-bms-integration.md`（集成）、`docs/research/jikong-proximity-autoconnect.md`（靠近自动连接）、`docs/research/jikong-handshake-fix.md`（握手修复）；阶段性总结见 `docs/research/jikong-summary.md`。
> 本文面向使用者，随功能迭代更新。

---

## 一、这是什么（30 秒看懂）

极空（JK）保护板是电动车锂电池常用的智能 BMS（电池管理系统），手机通过蓝牙连上它，就能实时看电量、电压、电流、温度、保护状态。

Bridge 客户端内置了这个能力，并比官方 APP 多了三样：

| 差异 | 说明 |
|---|---|
| **语音播报** | 连接自动播报电量、双击仪表盘播报、低电预警，后台锁屏也能听清 |
| **里程统计** | 里程台账 + 能耗曲线 + 花费计算，云端留档 |
| **靠近自动连接** | 手机带身上，靠近默认保护板就自动连上并播报，不用掏手机进页面 |

## 二、功能概览

| 能力 | 说明 |
|---|---|
| **扫描连接** | 蓝牙扫描极空设备、连接、设默认设备、改昵称 |
| **实时数据** | SOC 电量圆盘、单体电压、电流/功率、温度、保护/MOS 状态 |
| **语音播报** | 连接自动播报电量、双击播报、低电预警，后台锁屏音量拉满 |
| **里程统计** | 里程台账 + Canvas 能耗曲线 + 花费，同步到云端（MySQL 留档） |
| **时速仪表盘** | 时速 / 剩余续航 / 瞬时·平均电耗 / 本次里程（GPS，可选开启） |
| **靠近自动连接** | 后台免进页自动连、走远断、回来连，控制器级低占空比极省电 |
| **连接提示音** | 连接成功 beep 一声，5 种音色可选、可试听 |
| **演示模式** | 不连设备灌示例数据，核对界面效果 |

## 三、连接保护板

1. 底部导航进「极空」页；
2. 点「扫描极空设备」，在列表里选你的保护板点「连接」；
3. 连上后点设备名可**改名**、点「设为默认设备」——之后进页会自动直连默认设备，靠近自动连接也只认默认设备。

> 若列表里看不到设备，可打开「显示全部蓝牙设备（不按极空过滤）」（真机 UUID 与官方不一致时的兜底）。

## 四、四个页面怎么用

底部导航四个 Tab（首页在左）：

| Tab | 内容 |
|---|---|
| **首页** | 中央 SOC 弧仪表盘（电量 + 充电/放电/均衡状态胶囊）+ 时速仪表盘卡片 |
| **实时状态** | 电池电压 / 电流 / 功率 / 单体电压 / 温度 / 保护 / MOS 状态 |
| **统计** | 里程台账（记一笔 / 阶段统计）+ Canvas 能耗曲线 + 同步按钮 |
| **参数设置** | 时速仪表盘、靠近自动连接、语音播报、单位与花费、里程折扣等 |

首页双击仪表盘任意位置，会**立即播报**「电量 + 时速 + 剩余续航」（显式手势，即使静音也会播）。

## 五、语音播报

- **连接自动播报电量**：连上后每帧判定——电量变化即播；相同但超过播报间隔再播；跌破低电量阈值立即播「电量低，请注意充电」，之后按预警提醒间隔重复提醒。
- **双击播报**：首页双击仪表盘，绕过静音立即播一次完整状态。
- **音量提升**：每次播报前临时把媒体音量拉满、播完恢复（三段兜底，后台/锁屏也能生效）；默认「智能检测」——若检测到其他程序在放声音（听歌/看视频/导航）就不拉，避免打断；打开「强制提升」则无条件拉满。
- 需要设备装有系统文字转语音（TTS）引擎。

## 六、靠近自动连接（后台免进页）

打开设置页「靠近自动连接」开关后：

- 手机带身上，**靠近默认保护板就自动连上并播报电量**，全程不用打开极空页；
- 走远自动断开，回来自动重连；
- 在极空页手动点「断开」会暂停（重进页或重启 APP 恢复）；
- 后台监听用控制器级低占空比，**极省电、零流量**。

配套三个可调项（默认值已实测最优，一般不用动）：

| 设置 | 默认 | 说明 |
|---|---|---|
| 首连短戳时长 | 1.0s（0.1~1.0） | 快速戳醒休眠保护板，越小唤醒越快 |
| 半死链长等待时长 | 12s（1~60） | 兜底长等待，防反复空转 |
| 连接成功提示音 | 双嘀（5 选 1） | 连接成功 beep 一声，点选即试听 |

> 提示音与随后的「播报电量」之间的间隔，就是「连接成功 → 首帧数据」的耗时，不用看日志也能估算。

## 七、能做与不能做

**能做 ✅**

- 扫描连接、实时看电量/电压/电流/温度/保护状态
- 连接自动播报电量、双击播报、低电预警
- 里程台账记录 + 能耗曲线 + 花费（云端留档）
- 靠近自动连接、后台锁屏播报
- 演示模式（不连设备核对界面）

**不能做 ❌（或暂不做）**

- 保护板参数写入已从设置页移除（只读展示，防误改）
- 半死链场景需「首连 + 1 次直连重建」（约 2~3s），未做到官方「一次交互直接成功」（已稳定、可接受）
- 统计里程是自研扩展，非保护板原生数据

## 八、常见问题（FAQ）

**Q：连接后一直收不到数据、不播报？**
A：多是保护板「半死链」（BMS 休眠只回 AT 不出数据）。当前已自动处理——首连 1s 内无数据会自动断开换直连重建，约 2~3s 内出数据。若长时间（>1 分钟）仍无，看日志里的「半死链自愈」记录，或把手表靠近再试一次。

**Q：锁屏/后台播报声音很小？**
A：已在 v0.2.118 修复（三段兜底）。若仍小，检查「语音播报 → 播报时提升音量」是否开启；个别 ROM 会连兜底也拦，属系统限制。

**Q：偶尔播报的电量明显不对（比如突然报 10%）？**
A：已加帧校验（CRC），坏帧会被丢弃。若仍复现，请上传日志定位（大概率是保护板首帧字节错位的残留场景）。

**Q：靠近自动连接不触发？**
A：确认已设默认设备、开关已开、蓝牙已开。首次使用需先手动连一次并「设为默认设备」。

**Q：连接成功想听提示音，怎么换音色？**
A：设置页「靠近自动连接」卡内「连接成功提示音」，点 1~5 逐个试听，选中的即为最终音色。
