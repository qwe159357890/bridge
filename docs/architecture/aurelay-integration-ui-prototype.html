设计要点与待确认项：
  • 中转服务器可编辑：点击行弹出「修改中转服务器」输入框（复用项目已有「服务地址」编辑弹窗样式，host + port），保存后写入持久化（DataStore/SharedPreferences），下次连接生效。
  • 自动重连默认开 + 持久化 + 关闭二次确认：复用项目已有 CoreConfirmDialog（SettingsPages.kt 422-445 行）的机制与样式 —— ⚠️ 大图标 + 标题「关闭「自动重连」？」+ 说明文案 + 红色「确认关闭」按钮 + 「取消」按钮。关闭后持久化，避免误触导致中转掉线不恢复。
  • 配对机制（已按源码修正）：Aurelay 用 device_id + token 握手，无房间码/配对码。token 是客户端内部自动管理的身份凭证，不暴露在设置页，用户点「开始中继」即自动连接。
  • 后端对接（硬约束）：严格复用 Aurelay 现有协议、后端零改动，保证 Aurelay 原版 App 继续可用、与 Bridge 同时共存。客户端只复刻 RelayProtocol（ARLY 帧）+ RelayClient（出站 WS 连 039039.xyz:15151/api/aurelay/relay）+ OpusDecoder，绝不触碰服务端。
  • 音量语义：「中继音量」= 程序自身 AudioTrack 的软增益（setVolume(0~1f)），只影响中继播放，不动系统媒体音量（与 Aurelay 一致）。
  • 音量归位：音量滑块在主页面「音频中继」内，与波形同屏（对应 Aurelay 原版的「可视化条 + 音量滑块」中间区）。
  • 波形：还原 Aurelay RealAudioVisualizer —— 24 根上下对称柱 + 中心圆点，实时频段跳动，数据来自 AudioRelayService 的 ACTION_AUDIO_LEVEL 广播（24 维 float 数组）。波形下方不放多余文案，避免与柱子重叠。
  • 音量环：确认不加（仅保留柱状波形）。
