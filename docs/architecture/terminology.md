# 术语约定（三端叫法）

> 本文档统一 Bridge 项目「三端」的称呼，避免「客户端/APP/手机端」「api/服务端/后端」「管理后台/外部端/管理端」混用造成的歧义。所有文档、代码注释、沟通中均遵循本约定。

## 三端统一叫法

| 端 | 首选叫法 | 允许的同义别名 | 对应代码位置 |
|---|---|---|---|
| Android 手机上的应用 | **客户端** | 手机端、App 端、APK 端、APK、App | `app/` + `core/` + `feature/` |
| Python FastAPI 服务 | **服务端** | 服务器 | `server/` |
| Web 页面 | **管理后台** | 管理端、Web 端 | `admin/` |

## 规则

1. **首选叫法**：文档、代码注释、README 中一律优先使用「**客户端 / 服务端 / 管理后台**」。
2. **同义别名**：上表「允许的同义别名」可出现在口语、日志、临时描述中，语义等价，不算错误；但在**权威文档、正式说明、对外交付物**中应使用首选叫法。
3. **禁止混用歧义词**：以下旧称在正式文档中不再使用，避免混淆——
   - 「api」指代服务端（`api` 是服务端内部的路由目录 `server/app/api/`，不是「端」的称呼）；
   - 「外部端」指代管理后台（已统一为「管理端」或「Web 端」）。
4. **方向性表述**：三端之间的数据/调用关系统一用「客户端 ⇄ 服务端 ⇄ 管理后台」描述（客户端连服务端 WebSocket 长连接，管理后台调服务端 REST/WS 管理接口）。
